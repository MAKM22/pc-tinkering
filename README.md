# PC Tinkering

A practical notebook for computer enthusiasts who like to build, customize, understand, and troubleshoot their PCs.

## Topics

- PC parts, builds, upgrades, compatibility, and peripherals
- Operating-system setup, customization, and useful workflows
- Cooling, storage, networking, backup, and maintenance
- Performance measurements and reproducible benchmarks
- Troubleshooting notes with symptoms, diagnostic steps, and verified fixes
- Small scripts and projects for automating everyday computer tasks

## Sharing a guide

Record the hardware and software versions, relevant settings, steps taken, results, and any risks or limitations. Back up important data before system changes, use appropriate electrostatic-discharge precautions when handling components, and avoid sharing credentials or personal data. Distinguish tested results from hypotheses.

This repository is for lawful, safe experimentation. Do not publish malware, stolen data, or instructions intended to compromise systems you do not own or administer.
